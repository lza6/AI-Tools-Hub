## ★ TOP 3（一键安装 + 需求刚 + 差异化）

### 1. OfficeCLI — AI 专用 Office 套件
类型：CLI（单二进制，Apache-2.0）。给任何 AI agent 一行代码完全操控 Word/Excel/PPT，内置 HTML 渲染引擎形成"渲染→看→修"闭环，无需安装 Office。
安装命令原文：
```bash
# macOS / Linux
curl -fsSL https://raw.githubusercontent.com/iOfficeAI/OfficeCLI/main/install.sh | bash
# Windows (PowerShell)
irm https://raw.githubusercontent.com/iOfficeAI/OfficeCLI/main/install.ps1 | iex
# 或包管理器
brew install officecli
scoop install officecli
npm install -g @officecli/officecli
```

### 2. Panniantong__Agent-Reach — 给 Agent 一键装上互联网能力
类型：CLI/MCP 接入层。替用户选好、装好、体检好最稳的 agent 互联网接入方式，接入方式换代无需改动。GitHub Trending #1。
安装命令原文（待验证，以仓库 README 最新为准）：
```bash
pip install agent-reach
# 或 MCP 接入
npx agent-reach init
```

### 3. OpenLore — AI 编码 agent 的确定性记忆与护栏
类型：npm CLI（MIT）。local-first 静态分析：一次调用告知 agent 任务会触及哪些代码，一道门禁告知什么不能改，热路径无 LLM、无 API key、结果确定可复现。
安装命令原文：
```bash
npm install -g openlore
```
