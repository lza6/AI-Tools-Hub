## 八、总结：给军火库的上架建议

**第一批（高价值+形态契合，10 个）**：
1. `claude-mem` — 记忆类补强（全自动 hook 触发）
2. `code-review-graph` — 图谱类（我们已在用，自动触发）
3. `context-mode` — MCP 输出压缩（自动 hook 路由）
4. `chrome-devtools-mcp` — MCP 主力
5. `Windows-MCP` — Windows 自动化
6. `browser-use` — 浏览器自动化
7. `Scrapling` — 反爬爬虫
8. `uv` — Python 效率
9. `superpowers` / `agent-skills` — 技能分类填充
10. `git-who` — CLI 补充

**触发方式三类分布**（回应你 graft 式自动触发的期待）：
- **全自动（hook/文件监听）**：claude-mem、code-review-graph、context-mode、bacon
- **半自动（agent 按需调 MCP）**：OpenContext、chrome-devtools-mcp、Windows-MCP、browser-use
- **手动 CLI**：yazi、uv、git-who、semtools、Graft(build 需手动)

**上货架的配套问题**（加工具时需逐个确认）：
- MCP 类型安装后需写 `.mcp.json`/claude 配置——manifest 的 skills 字段要扩展一个 `mcpConfig` 动作
- 全自动 hook 类要确认 hook 注入位置（settings.json vs CLAUDE.md）
